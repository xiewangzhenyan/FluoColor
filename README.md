# FluoColorQuant - 比色-荧光高通量传感检测软件

## 项目概述
FluoColorQuant 是一款专业的比色-荧光高通量传感检测软件，结合了专业的光学检测器件和智能手机的高分辨率摄像头、高性能处理能力以及丰富的计算资源，为生化材料的浓度定量测量提供高效、便捷的解决方案。本软件的检测模式分为荧光检测模式（Fluorescence Mode）和比色检测模式（Colorimetric Mode）。检测的对象就是用户拍照或者从相册中选择的孔阵图片（目前主要是96孔阵图片，12行8列）。孔阵的定位方式，使用已经训练好的Mask R-CNN模型（模型文件名叫model_final.pth）进行定位分割孔阵图片（会切割出96张小孔阵图片）。或者让用户通过手动选取的方式，给出截取之后的孔阵图片。结果展示部分分成两类，第一类，如果用户一开始使用的是R-CNN模型的自动识别功能的话，最后结果部分使用改进的CNN模型训练好的浓度模型——improved_concentration_model.pth进行浓度预测，生成一张预测 vs 真实值散点图（带R²），或者预测浓度热力图（对应96个孔阵）。第二类，如果用户使用的是自己截取的话，最后结果部分直接根据截取的孔阵图片，调用improved_concentration_model.pth模型给出预测的浓度值。


## 功能模块
1. **用户管理**
   - 用户注册与登录
   - 用户认证与授权
   - 登录状态维护

2. **检测功能**
   - 图像采集（相机/相册）
   - 图像处理（裁剪/旋转/校正/增强）
   - 孔阵检测（Mask R-CNN/手动选择）
   - 浓度预测（CNN模型）
   - 结果分析（散点图/热力图）

3. **项目管理**
   - 新建检测项目
   - 历史记录查询与管理

## 技术架构
- **前端框架**: Jetpack Compose
- **架构模式**: MVVM
- **数据持久化**: Room
- **网络请求**: Retrofit
- **依赖注入**: Hilt
- **机器学习**: TensorFlow Lite/PyTorch Mobile
