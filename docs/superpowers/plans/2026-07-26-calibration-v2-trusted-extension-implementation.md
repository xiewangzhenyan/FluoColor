# 2026-07-26 标定 V2、可信扩展估计与不可定量分层实施记录

## 一、目标

本工作包用于解决现场标准点较少时，4PL/5PL 端点不稳定、未知样品被大面积笼统标记为
“超出量程”、严重饱和仍可能保存点浓度以及结果页统计语义不闭合的问题。

最终用户只看到三类互斥结果：

1. **定量**：位于真实标定范围内，模型和位点质量均通过。
2. **估计**：位于标定范围外，但仍落在由留一验证、参数不确定性和渐近线距离共同确定的
   可信估计范围内。
3. **复测**：严重饱和、区间过宽、反算不稳定或只能确定单侧界限，禁止伪造精确浓度。

三类计数必须严格相加等于当前分析物的适用且已测位点数。项目预期范围继续用于实验规划、
色带和范围提示，但不再同时承担所有模型的无限外推截断职责。

## 二、不可变约束

- 96 孔板与微流控共用标定、推荐、反算、不确定性和定量状态领域能力。
- 圆孔定位、PG-Grid、两套独立结果页面和模态专用信号处理继续保持独立。
- 历史运行只读取冻结快照，不重新拟合、不重新计算、不改变旧浓度。
- 未知样品的越界数量不得参与模型推荐，避免数据泄漏和人为压低越界数。
- 浓度定义域从数学层保证 `x >= 0`；负净信号可以保留，但不能产生负浓度。
- 严重饱和、不可辨识区间或渐近线附近信号不得输出伪精确浓度。
- 所有新增用户文本进入中英文字符串资源，所有新增 UI 使用 Compose 和 Material 3。

## 三、领域设计

### 3.1 四类范围

| 范围 | 来源 | 科学含义 |
| --- | --- | --- |
| 标定范围 | 真实标准浓度最小值和最大值 | 有实验点支持的内插范围 |
| 项目预期范围 | 用户创建项目时填写 | 实验规划、色带和预期提示 |
| 可信估计范围 | V2 模型验证和参数采样生成 | 可输出带估计语义与区间的连续外推范围 |
| 数学信号域 | 曲线函数及其渐近线 | 只用于内部判断是否存在反函数 |

### 3.2 逐孔定量状态

稳定机器状态计划为：

- `QUANTIFIED`：标定范围内点浓度。
- `ESTIMATED`：可信范围内的标定范围外估计。
- `BOUND_ONLY`：仅能报告 `<下限` 或 `>上限`。
- `UNAVAILABLE`：信号、模型或质量证据不足，无法定量。

结果页将 `BOUND_ONLY` 和 `UNAVAILABLE` 统一归入“复测”，但数据库、CSV、PDF 和单孔详情必须
保留二者的科学差异。

### 3.3 富观测输入

标准点和未知孔不再只向量化器传入 `Double`，而是携带：

- 主信号值；
- `saturationRatio`；
- `qualityReliable`；
- 光度 flags；
- 特征类型；
- 左/右删失方向及可解释的信号边界。

## 四、算法设计

### 4.1 自动模型族

- 线性安全基线；
- 有零浓度或空白证据时启用约束 3PL；
- 约束 4PL；
- 对不对称参数施加收缩的正则化 5PL；
- 旧推荐算法作为冻结回退基线。

普通自动推荐只使用上述安全模型族。其他专家函数继续可选，但首期不获得可信范围外推资格。

### 4.2 鲁棒与异方差

- Student-t 残差自由度首期固定为 `4`，不在稀疏标准点上额外估计。
- 有足够重复孔时使用按浓度水平估计并向全局方差收缩的权重。
- 重复孔不足时比较等权、`1/|y|`、`1/y²` 三种固定权重，并由留一验证裁决。
- 可解释的贴顶信号进入单侧删失似然；无法建立数值边界的特征只保留饱和证据，不伪造边界。

### 4.3 浓度水平留一

每次移除一个完整浓度水平及其全部重复孔，重新拟合后反算被留出的标准点。记录：

- 留一成功率；
- 留一反算误差中位数；
- P90 误差；
- 最低和最高浓度端点误差；
- 标准点反算 RMSE；
- 参数采样有效率；
- 模型复杂度和 R²。

推荐顺序为：数学有效 → 留一成功率 → 端点误差 → 总体留一误差 → 标准点反算误差 →
参数稳定性 → 模型复杂度 → R²。

### 4.4 参数采样与可信范围

- 在变换后的参数空间计算惩罚 Hessian。
- Hessian 稳定时按输入指纹生成 256 组确定性参数样本。
- Hessian 不可逆、条件数过大或有效样本不足时关闭可信扩展。
- 首期最多检查到项目上限的 1.5 倍；扫描中首次失败后立即结束，保证可信范围连续。
- 可信门槛首期包括：95% 参数样本可反算、95% 区间相对宽度不超过 50%、信号距离渐近线
  不少于三个残差尺度、端点留一无失败、位点没有严重饱和或裁切。

这些阈值必须通过项目 6575 的真实数据、项目 963 回归和确定性合成真值校准后再冻结。

## 六、交互设计

### 6.1 现场标定

结果首屏直接显示：

```text
系统推荐                         [质量良好]
线性
积分荧光强度
反算误差  6.8%      标定范围  6–89 g/ml
[应用推荐曲线]       [其他曲线]
```

公式、R²、留一误差、端点误差、可信外推和模型风险进入“其他曲线”内联区域，不在主卡堆叠。
可信外推没有通过稳定性门槛时显示“未启用”，不展示容易被误读为用户漏填的内部参数空状态。
应用成功后自动关闭弹窗并继续检测流程；用户之后主动重新打开时仍可查看已经冻结的候选结果。

### 6.2 结果页

三张统计卡改为互斥分类：

```text
定量    估计    复测
```

- 定量：正常浓度色带；
- 估计：浓度色带加低干扰琥珀色小三角；
- 复测中的单侧界限：按方向投影到当前色带低端或高端，并叠加箭头；真正不可用才使用浅灰底；
- 单孔估计值使用 `≈`；单侧界限使用 `<` 或 `>`；
- 项目预期范围、标定范围和区间详情保留在单孔展开与导出中。
