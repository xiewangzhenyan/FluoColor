## 目标

1. 标准曲线必须绑定分析物、检测模式、主信号、处理器版本和浓度单位。
2. 普通用户只录入已知浓度；信号值通过应用检测结果或结构化 CSV 导入获得。
3. CSV 支持一列浓度和多列候选信号，已知标题自动识别，歧义时由用户确认映射。
4. 比色与荧光共用拟合引擎和界面，但不共用同一个曲线实例。
5. 直接新建项目自动筛选兼容模型；无模型时继续仅信号模式。
6. 项目冻结分析模型快照，结果能够追溯模型、主特征、单位和拟合参数。
