# 统一阵列信号与拟合函数实施记录

> 日期：2026-07-25  
> 范围：96孔板与微流控芯片共用的现场标定信号、拟合函数、推荐规则与交互

## 已确认现状

- `FittingFunction` 中现有20种函数仍完整保留，数学内核没有被删除。
- 新阵列现场标定目前只接入 ΔE2000、光密度、经典灰度、R/G/B、RGB平均值等少量信号。
- 当前比色信号入口错误地要求所有特征都必须存在参考孔，导致绿色通道、经典灰度等直接信号在拟合前被过滤，出现“没有有效信号”。
- 旧 `PixelType` 与 `SignalFeatureCatalog` 已保留31种颜色特征，可作为统一扩展的兼容基础。

## 本轮实施步骤

1. 按信号语义区分参考依赖，先修复96孔板无参考孔时直接信号无法拟合的回归。
2. 扩展统一比色主特征，明确把 `0.299R + 0.587G + 0.114B` 作为首要推荐信号。
3. 将自动候选函数扩展为线性、二次、指数、对数、幂函数、4PL、5PL；全部现有函数继续供手动选择。
4. 现场标定高级选择升级为多选配置，普通用户保持自动推荐，科研用户可以指定信号和函数集合。
5. 96孔板与微流控继续复用同一个 `GridDetectionCoordinator`、`ArrayCalibrationEngine` 和推荐引擎，载体差异只保留在定位、裁切及形状掩膜层。
6. 补齐单元测试、生产构建、设备安装和ADB截图复核。

## 设计约束

## 最终实现记录

### 统一信号

- 经典灰度 `0.299R+0.587G+0.114B` 固定为比色推荐列表首项。
- 比色信号按推荐、扩展、兼容、实验四级管理；旧信号编码继续用于历史兼容。
- 直接RGB、灰度、Lab等信号不再错误依赖参考孔；真正需要参考校正的信号仍保持科学门控。
- 96孔板与微流控共用 `ArrayCalibrationEngine` 和信号矩阵，不再维护两套现场拟合逻辑。
- 多选信号进入项目、实验模板和运行快照，旧单选快照继续兼容读取。

### 统一函数

- 默认常用函数为线性、二次、指数、对数、幂函数、4PL、5PL。
- 专家函数保持完整，现场标定支持手动多选本次候选集合。
- 标准曲线库、96孔板和微流控统一调用 `FittingEngine.fitRequestedCalibrationFunctions()`。
- 对数与幂函数增加定义域检查，禁止静默丢弃零浓度或负响应标准点。
- 最终定量读取冻结候选参数，不在应用曲线后再次拟合。

### UI收敛

- 信号列表删除逐项长说明，保留复选框、短名称和必要公式。
- 现场标定与系统“曲线拟合设置”共用 `analysisFeatureIcon()`，避免同一信号出现不同图标语义。
- 图标按公式、颜色、光学、比值、荧光、光谱分类；净荧光、积分荧光和SNR使用不同图标。
- 图标采用32dp低饱和度底板和18dp单色矢量，辅助快速扫描但不抢占科研数据视觉层级。
