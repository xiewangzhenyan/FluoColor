# 2026-07-24 阵列定量与结果页综合修复实施记录

## 目标

本轮针对真实 15×15 微流控运行暴露的问题进行完整修复，重点保证：

1. 项目预期量程、曲线标定范围和验证范围不再互相覆盖。
2. 所有具备有限信号的位点都会尝试反算，范围外结果保留数值并明确标记。
3. 现场拟合展示真实失败原因，低质量曲线不再因为反算通过率高而被误判为推荐。
4. 结果页收敛为“结果 / 分析 / 过程”，删除重复表格、独立原图页和一级质控页。
5. 普通光度提示、低信号和范围状态不再改变测量质量；只有冻结的可靠性失败或严重光度风险才提示复核。
6. 不修改首页、历史列表、关于页、Pager 和底部导航。

## 已确认的真实运行基线

- 运行总位点：225。
- 有限信号：225。
- `qualityReliable=true`：225，有限信号：225。
- 当前定量分布：曲线范围内 61、曲线外推 127、超出项目量程 37。
- 旧结果页把 164 个范围状态与 25 个普通光度提示合并，错误显示为 189 个“建议复核”。
- 项目分析物最大浓度仍为 `100 g/ml`，但现场标准点 `28–34 g/ml` 被错误写入分析模型和模板的 `reliableRange`。
- 标准点为 8 个、7 个独立浓度水平；4PL/5PL 不可用的主因是信号趋势非单调，而不是点数不足。
- 线性候选 `R²=0.1774`，旧“接受率=100%”只是宽松容差下的标准点反算通过率，不能代表曲线拟合质量合格。
